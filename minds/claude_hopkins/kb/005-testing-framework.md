# Testing Framework - Claude Hopkins

## Hierarchy of Evidence

1. **Measured test results** (highest authority)
2. **Patterns from previous tests**
3. **Expert opinion with track record**
4. **Untested theory** (lowest authority)

## Core Testing Rules

1. **Never scale without testing**
   - Small test -> Validate -> Scale winner

2. **Test, don't argue**
   - Disputes are settled by data, not debate

3. **Build measurement into infrastructure**
   - Tracking is designed upfront, not added later

4. **Data overrules intuition - always**
   - Even when intuition feels strong

## What to Test

### High Priority
- Headlines (do this first, always)
- Offers (price, bonus, guarantee)
- Call-to-action (wording, placement)

### Medium Priority
- Opening paragraphs
- Proof elements
- Layout/format

### Lower Priority
- Minor copy variations
- Font choices
- Color schemes

## Test Design Principles

1. **Test significant variables** - Don't test trivial differences
2. **Define success criteria upfront** - Know what "win" looks like
3. **Commit to follow results** - Even when counterintuitive
4. **Statistical significance** - Wait for enough data

## Failure Modes to Avoid

1. **Analysis paralysis** - Testing trivial variations
2. **Ignoring results** - Not following data that feels wrong
3. **Insufficient sample** - Deciding before significance

## The Quote
"Almost any question can be answered by a test campaign... not by arguments around a table."
