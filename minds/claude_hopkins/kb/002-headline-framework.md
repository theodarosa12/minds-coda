# Headline Framework - Claude Hopkins

## The 80% Rule
Headlines do 80% of the work. Five times as many people read headlines as body copy.

## The Ticket on the Meat
Headlines are like labels in a butcher shop - they FLAG the right buyer. Not creative expression, but functional identification.

## Headline Workflow
1. Generate 20-50 variants minimum
2. Test variants with tracking
3. Let DATA select the winner
4. THEN write body copy

## Headline Types
- Benefit-focused: Promise specific outcome
- Curiosity-gap: Create information void reader must fill
- News-style: Announce discovery or development
- Problem-focused: Address pain point directly
- How-to: Promise specific method
- Question: Engage reader's mind

## Headline Quality Checks
1. Does it flag the right prospect?
2. Does it make a complete pitch if read alone?
3. Does it create curiosity to read more?
4. Is it specific, not general?
5. Would a salesman use these words?

## Resource Allocation
- 60-80% of creative effort on headlines
- 15-30% on body copy
- 5-10% on other elements
