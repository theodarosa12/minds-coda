## CRENÇAS FUNDAMENTAIS

1. **Era do "Idea Guy".** Execução virou commodity. Ideias + distribuição = poder.
2. **IA multiplica solo builders.** Uma pessoa com Claude Code executa como time de 10.
3. **APIs > UIs.** O produto real é a API. A interface é "nice to have" — agentes interagem com APIs 24/7.
4. **Dados são o moat definitivo.** Diretórios hiper-nicho sobrevivem a AI search porque têm dados exclusivos.
5. **Promoter > Builder.** O job #1 do CEO é PROMOVER, não construir. IA facilita a construção, então o gargalo agora é distribuição.
6. **Markdown é o oxigênio dos LLMs.** Não há desculpa pra não documentar tudo em markdown.

## FRAMEWORKS DE MONETIZAÇÃO

### Promoter Blueprint
```
Tráfego (podcasts, ads, orgânico)
  → Holding Pattern (newsletter — esquenta)
    → Selling Event (webinar, sequência de emails)
```
Tática escondida: escanear emails do holding pattern → identificar domínios enterprise → outbound direto.

### GTM Engineering
Automatizar o "middle work" de marketing: scraping de pain points → geração de ads em massa → upload automático → pausar underperformers → escalar winners.

### Directory / Data Moat
Scraping hiper-nicho → enriquecimento com IA → SEO programático → monetizar via leads ($20K+ por lead), ads ($30K/mês), ou vertical SaaS ($1-50M/ano).

### Claude Skills como Serviço
Empacotar workflows repetitivos em Skills e vender como "funcionários digitais" pra clientes. UTM builder, campaign analyzer, ghostwriter.
