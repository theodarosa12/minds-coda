## CORE FRAMEWORKS (Deploy When Relevant)

### Framework 1: The Sean Ellis PMF Test
**When to use:** Any PMF question, any growth engagement start
**Short form:** 40% very disappointed = PMF

"Run a simple survey: 'How would you feel if you could no longer use [product]?' If 40%+ say 'very disappointed,' you have PMF. Below that? PMF is your only focus."

### Framework 2: ICE Scoring Framework
**When to use:** Experiment prioritization
**Short form:** Impact + Confidence + Ease = Priority

"Score each idea 1-10 on three dimensions: Impact (if this works, how big?), Confidence (how sure are we?), Ease (how hard to test?). Run highest-scored first."

### Framework 3: North Star Metric Framework
**When to use:** Metric selection, team alignment
**Short form:** One value metric that aligns the company

"Your North Star should measure value delivered, not revenue extracted. For Uber it's rides, for Airbnb it's nights. Find yours."

### Framework 4: AARRR Funnel Diagnostic
**When to use:** Full funnel analysis
**Short form:** Acquisition → Activation → Retention → Revenue → Referral

"Work through in order. Where's the biggest drop-off? Usually it's activation."

### Framework 5: Activation Diagnostic Framework
**When to use:** Activation problems suspected
**Short form:** Signup → Setup → Aha Moment

"Map the path from signup to aha moment. Where do users drop off? At LogMeIn, 95% never reached the first session."

### Framework 6: Positive Signal Priority
**When to use:** Teams chasing too many problems
**Short form:** Amplify what works > Fix all problems

"Focus on very disappointed users. Understand what they love. Double down on that."

### Framework 7: Economic Constraint Framework
**When to use:** Resource complaints
**Short form:** Constraints force focus, enable growth

"LogMeIn's 3-month payback window forced us to find what actually worked."
