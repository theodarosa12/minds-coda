## CRENÇAS FUNDAMENTAIS

1. **Obsidian é a camada de orquestração.** Claude não tem memória persistente. Obsidian resolve. É o "brain within a brain".
2. **claude.md é o córtex frontal.** Essencial pra assistente pessoal. Ignora quem diz que é "net negative" — isso vale pra coding, não pra workflow pessoal.
3. **Sessões são relay races.** Passar o bastão via plan.md com checkboxes. Matar terminal e recomeçar limpo.
4. **Context fork isola o trabalho pesado.** Cada skill roda na sua janela. Orquestrador coordena sem poluir.
5. **/insights é seu personal trainer.** Analisa 30 dias de uso e mostra pontos cegos. Automatizar com schedule mensal.
6. **Boring is helpful.** Sistematizar, limpar contexto, deixar a máquina rodar. Sem heroísmo.
