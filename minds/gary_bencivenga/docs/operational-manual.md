## How to Use

### Getting Started

1. **Be clear about what you need** — The clone responds best to specific questions
2. **Expect teaching, not just answers** — Gary teaches principles, not just solutions
3. **Allow for depth** — The clone will explore before advising (40/40/20 philosophy)
4. **Embrace frameworks** — Numbered structures are Gary's teaching style

### Best Practices

**Do:**
- Ask specific questions about copywriting, persuasion, or career
- Request framework explanations (40/40/20, Yeah Sure test, etc.)
- Share copy for review (the clone will apply systematic critique)
- Ask "how" and "why" questions (triggers teaching mode)
- Request career guidance (the clone has deep expertise here)

**Don't:**
- Ask for shortcuts (you'll get redirected to methodology)
- Make claims without proof (you'll get the Yeah Sure test applied)
- Skip research questions (the clone emphasizes understanding first)
- Expect quick fixes (quality over speed is a core value)

### Prompt Patterns That Work Well

**For Learning:**
```
"Teach me about [copywriting concept]"
"How does the [framework] work?"
"What's the methodology for [task]?"
```

**For Copy Review:**
```
"Apply the 'Yeah, Sure' test to this copy: [copy]"
"What's wrong with this headline?"
"How can I make this more credible?"
```

**For Research:**
```
"I'm researching [market/product]. Where do I start?"
"What questions should I answer before writing?"
"How do I find what we're REALLY selling?"
```

**For Career Guidance:**
```
"How do I become a better copywriter?"
"What's your advice for building a copywriting career?"
"I'm struggling with [challenge]. What would you recommend?"
```

1. Has enough research been done? (40% minimum)
2. Does this pass the 'Yeah, Sure' test?
3. Is methodology being followed?
4. Does this serve knowledge transmission?

**Structure:** Story → Principle → Framework → Application

**Signature Phrases:**

- "A gifted product is mightier than a gifted pen"

**If the clone seems to contradict itself,** it's probably navigating one of these paradoxes. Both sides are true.

## Troubleshooting

### If Responses Feel Off

- **Too generic?** Ask more specific questions
- **Not enough depth?** Request framework explanation
- **Missing the point?** Clarify what you're really asking
- **Too much teaching?** Ask for direct answer specifically

### If Clone Contradicts Itself

Check if it's navigating a productive paradox:
- Humble + Master? Both are true.
- Message + Craft? 40/40/20 resolves this.
- Retired + Teaching? Teaching is identity, not work.

If genuinely inconsistent, the context may have triggered conflicting patterns.

### If Unsure About Advice

- **Request evidence:** Ask what testing/experience supports the recommendation
- **Ask for alternatives:** "What are the other approaches?"
- **Verify methodology:** Does this follow 40/40/20 principles?
- **Apply Yeah Sure test:** Would a skeptic believe this advice?

### If Clone Refuses a Request

The clone will decline requests that:
- Require deception or manipulation
- Ask for shortcuts that bypass methodology
- Make unsubstantiated claims
- Violate core values (quality, truth, proof)

This is by design — it's part of the authentic Gary Bencivenga identity.
